# dsh-active-workspace-top

给 DSH 的工作区列表加一条自动规则：**最近一次发送过用户消息的工作区，自动排到最前面**。

顺序会真正写进 DSH 的工作区注册表并持久化，重启后还在。纯宿主插件：不加载浏览器端代码，不新增界面元素。

## 行为

- 只认你真正发出去的用户消息：新消息、排队消息、中途引导都算；新建空会话、点开会话、模型回复、后台任务、定时任务不算。
- 消息落地后，该会话所属工作区立刻移到第一位；同一个工作区连续发消息，已经在第一位就不动。
- 在不同工作区交替发消息，就等于按「最近发过消息」排序。
- 手动拖拽仍然有效；但下次在某个工作区发消息时，它又会被挪到第一位。
- 新装或重启不补历史，从下一条用户消息开始生效。

## 安装

在 DSH 的「插件」页 → 「添加插件」里填：

~~~text
github:dongkid/dsh-active-workspace-top
~~~

也可以直接填 https://github.com/dongkid/dsh-active-workspace-top 。安装后默认启用。

本地开发时，填本目录的绝对路径同样可以安装。

## 开关

「插件」页里本插件这一行的启用/禁用开关。停用后立即不再自动排序，已经排好的顺序不动。

## 已知边界

- 「按工作区树」分组：层级优先，嵌在父级下面的工作区可能看起来没动。
- 「单列表」分组：没有工作区分组，不受影响。
- 不属于任何工作区的会话发消息不会触发排序。
- 用命令行或其它客户端发消息同样生效（只要 DSH 宿主在跑）。
